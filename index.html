rclone 文件中转 / rclone File Transfer

Google 授权应用名称 / Google consent-screen app name: rclone
个人自用配置，不是 rclone 项目的官方服务。
Personal-use setup, not an official rclone service.

用途 / Purpose
这是账号所有者个人使用的文件中转配置，使用开源 rclone，在所有者授权的云电脑、Google Drive 和 Mac 之间上传和下载工作文件。它不是面向公众提供的文件存储服务，也不是 Google 或 rclone 项目的官方服务。
This is a personal file-transfer setup using open-source rclone to upload and download the owner's work files between an authorized cloud computer, Google Drive, and a Mac. It is not a public file-storage service or an official service of Google or the rclone project.

权限 / Permissions
配置请求 https://www.googleapis.com/auth/drive.file 权限，用于创建中转文件和文件夹，并读取、下载或更新该应用获准访问的文件。它不请求访问整个 Google Drive 的权限。只有账号所有者或其明确授权的执行环境使用此配置。
The setup requests the drive.file scope to create transfer files and folders and read, download, or update files accessible to this application. It does not request full-Drive access. It is used only by the account owner or execution environments authorized by the owner.

操作方式 / How it works
所有者授权后，rclone 在云电脑与 Google Drive 之间上传文件，Mac 上的 rclone 再下载指定文件。文件不会因为发布本介绍页而变成公开文件。本网站只提供说明，不接收文件、账号密码或 OAuth 凭据。
After authorization, rclone uploads files from the cloud computer to Google Drive, and rclone on the Mac downloads the selected transfer files. Publishing this information page does not make those files public. This website provides information only and does not accept file uploads, account passwords, or OAuth credentials.

隐私政策 / Privacy policy
请查看本网站的 Privacy / 隐私政策页面。
See the Privacy page on this website.

个人使用与联系 / Personal use and contact
本配置仅供所有者自用，不开放公众注册。所有者可通过 Google 授权页面显示的支持联系渠道管理此配置。
This setup is for the owner's personal use and has no public registration. The owner can manage it through the support contact identified on the Google consent screen.
