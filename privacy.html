隐私政策 / Privacy Policy
rclone 文件中转 / rclone File Transfer
更新日期 / Last updated: 2026-11-14

Google 授权应用名称 / Google consent-screen app name: rclone
个人自用配置，不是 rclone 项目的官方服务。
Personal-use setup, not an official rclone service.

1. 范围与用途 / Scope and purpose
本政策描述账号所有者自用的 rclone 文件中转配置。Google 用户数据仅用于所有者要求的上传、下载、文件列表、完整性检查及相关中转管理，不用于广告或出售。
This policy describes the account owner's personal rclone file-transfer setup. Google user data is used for the owner's requested uploads, downloads, file listing, integrity checks, and related transfer management, not advertising or sale.

2. 访问的数据 / Data accessed
通过 drive.file 权限，配置可处理该应用创建或获准访问的文件及文件夹，包括内容、名称、大小、修改时间、文件标识符和校验信息。OAuth 授权产生的访问令牌和刷新令牌用于维持授权连接。此配置不请求完整 Google Drive、Gmail、通讯录或日历权限。
Using drive.file, the setup can process files and folders created by or authorized for this application, including file contents, names, sizes, modification times, identifiers, and integrity information. OAuth access and refresh tokens maintain authorized connections. The setup does not request full Google Drive, Gmail, contacts, or calendar access.

3. 数据流转与存储 / Processing and storage
选定文件在所有者授权的云电脑、Google Drive 和 Mac 之间传输，并可分别保存在这些位置。rclone 是这些电脑上运行的软件；此配置没有额外向 rclone 项目运营者上传文件的中转服务器。Google 处理 Google Drive 和 OAuth 请求；云电脑平台处理其环境内的文件及所有者授权的执行活动。相关平台另有自身的条款和隐私政策。连接凭据保存在受访问权限保护的本地配置文件中，不发布到本网站或公共代码仓库。
Selected files are transferred between, and may remain on, the owner's authorized cloud computer, Google Drive, and Mac. rclone runs as software on these computers; this setup does not add a relay server operated by the rclone project. Google processes Drive and OAuth requests, and the cloud-computer platform processes files and owner-authorized execution within its environment. These providers have their own terms and privacy policies. Connection credentials are stored in local configuration files protected by access permissions, not published on this website or in a public code repository.

4. 使用和披露 / Use and disclosure
此配置不出售 Google 用户数据，不用于定向广告，也不以发布本网站为由公开工作文件。所有者明确要求的传输会将文件交给所选存储和执行平台处理。所有者另行发起的文件分享不属于发布本说明页这一行为。
This setup does not sell Google user data, use it for targeted advertising, or make work files public by publishing this website. Owner-requested transfers send files to the selected storage and execution platforms. Any separate sharing requested by the owner is distinct from publication of this information page.

5. 保留、删除与撤权 / Retention, deletion, and revocation
没有统一的自动清理期限；所有者决定各处副本和操作日志保留多久。所有者可在 Google Drive 和各电脑删除文件，在 Google 账号的第三方连接设置撤销该应用权限，并停止 rclone 或移除本地配置。撤销权限不会自动删除已经下载或上传的副本；各平台的垃圾箱、备份和保留规则可能继续适用。
There is no single automatic cleanup period; the owner controls retention of copies and operational logs. The owner can delete files in Drive and on each computer, revoke this application's access in the Google Account's third-party connections settings, and stop rclone or remove local configurations. Revocation does not automatically delete existing uploaded or downloaded copies. Each platform's trash, backup, and retention rules may still apply.

6. 本说明网站 / This information website
本站不设置账号注册、上传表单、广告或由本页面加入的分析追踪脚本。网站托管方可能按其自身政策处理访问日志及提供网站所需的技术数据。
This website has no account registration, upload forms, advertising, or analytics scripts added by these pages. Its hosting provider may process access logs and technical data under its own policies.

7. 联系与更新 / Contact and changes
这是个人自用配置。有关权限和数据的管理，请使用 Google 授权页面显示的支持联系渠道；所有者也可直接管理上述账号与设备。配置用途或数据处理方式改变时，应相应更新本政策。
This is a personal-use setup. Use the support contact shown on the Google consent screen for permission and data-management questions; the owner can also manage the accounts and devices directly. This policy should be updated when the setup's purpose or data practices change.
